## 👨‍💻 About Me

I'm a **Full-Stack Developer** focused on building software that is scalable, maintainable, strongly typed and ready for real-world production environments.

My work spans **frontend applications, backend systems, APIs, databases, AI integrations, automation, cloud infrastructure and deployment engineering**.

I care about more than making software work. I enjoy designing systems with clear boundaries, predictable behavior, reliable deployment workflows and architecture that can evolve without becoming difficult to maintain.

I currently spend most of my time around:

- ⚙️ **Backend systems, APIs and application architecture**
- 🧠 **LLMs, AI Agents, tool calling and AI-powered applications**
- ☁️ **Cloud infrastructure, Linux, containers and deployment automation**
- 🏗️ **Clean Architecture, DDD and modular software design**
- 🔄 **Automation, integrations and intelligent workflows**
- 📱 **Cross-platform development with Flutter & Dart**
